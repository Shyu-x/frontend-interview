# MiniCode 可运行伴随项目

这是 `docs/minicode/` 七天课程的统一 TypeScript 工程。它不是七组互不相关的代码片段；每天都在同一套消息、工具、会话和任务契约上增加能力。

## 运行

需要 Node.js 22.18 或更高版本。

```bash
npm ci
npm run verify
npm run demo
```

测试默认使用 `FakeModel`，不会访问外部模型，也不需要 API Key。接入真实模型时，实现 `ModelAdapter`，并把供应商差异收敛到适配器中。

| 前端加练 | `ui-state.ts` | runId、序号、幂等重放、审批和工具卡状态 |

## 完成标准

- 工具错误会作为 observation 回到消息历史，而不是让整个会话崩溃。
- 轮数、工具次数和 token 都有独立预算。
- JSONL 最后一行被中断时可以恢复；中间损坏必须报错。
- 文件路径无法通过 `..` 或符号链接逃出工作区。
- 子任务有目标、非目标、输入、写入所有权、预算和证据。
- 父任务取消会传播给子任务；一个子任务失败不会抹掉其他结果。
- 多 Agent 报告包含成功率、证据覆盖率、重复证据率和写冲突数。

生产使用前仍应补上真实模型适配、供应商重试/限流、沙箱进程、秘密管理和持久任务队列。本项目刻意把这些边界写清楚，不把教学实现冒充生产框架。

## 必须理解的边界

- token 用量依据适配器返回值，检查发生在请求之后；没有 usage 的适配器不能证明预算准确。
- worker 必须在步骤边界调用 `BudgetMeter.charge`；调度器不会拦截任意代码的模型请求。
- 超时和取消停止等待并传播信号，不能杀死非合作函数、撤销写入；因此只有合作 worker 的实际资源并发受限。
- `ownedPaths` 是调度合同检查，不是文件系统沙箱；`realpath` 检查也存在检查到使用之间的竞态。
- 权限注册表默认拒绝标为 mutates 的工具；读工具也可以联网或泄漏数据，因此接入方仍须正确分类、配置授权钩子。
- 历史“压缩”是有长度限制的有损摘录，不是语义摘要；保留完整轮次可能超过 keepLatest 条数。
- 文件记忆只在同一个实例内串行写，rename 不等于跨进程事务或断电持久性。
- UI reducer 是客户端投影，不是授权服务器或 SSE 恢复协议实现；文本节点也不是完整的 XSS 防护方案。
