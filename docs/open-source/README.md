## 🤝 贡献指南

### 添加新项目

1. 搜索 GitHub Trending，找到符合条件的项目：
   - ⭐ 1000+
   - 📦 6 个月内活跃更新
   - 📖 完整 README/文档

2. 按模板创建文档：
   ```markdown
   ## [项目名] - 一句话描述

   ### 简介
   - 定位：解决什么问题
   - 特点：核心优势

   ### 技术栈
   - 语言/框架/依赖

   ### 使用场景
   - 典型用例

   ### 快速开始
   - 核心代码示例（JS/TS）

   ### 参考链接
   - GitHub / 文档 / 社区
   ```

3. 添加 Mermaid 架构图：
   ```mermaid
   flowchart LR
       A[组件] --> B[逻辑]
       B --> C[输出]
   ```

4. 更新本 README 和 `docs/open-source/index.md`

### 内容规范

- ✅ 使用 TypeScript/JavaScript 代码示例
- ✅ 添加 Mermaid 架构图（流程有分支/多路径时）
- ✅ 包含竞品对比表格
- ✅ 提供性能基准数据
- ❌ 避免简单线性流程图（用表格代替）
