# 组件与版式

组件的作用是让读者一眼看出"这段话的角色"。角色相同，样式就必须相同。

## 提示块

| 写法 | 角色 | 内容限制 |
|---|---|---|
| `!!! note` | 补充一个读者可能想知道的背景 | 不超过 4 行 |
| `!!! tip` | 给出更好的做法或学习路径 | 必须能立刻照做 |
| `!!! warning` | 指出易错点与陷阱 | 必须写出错误现象与原因 |
| `!!! danger` | 安全风险与不可逆操作 | 必须写出后果 |
| `!!! example` | 一个可运行的最小例子 | 必须带预期输出 |
| `!!! question` | 自测题 | 答案放在折叠块里 |

示例：

!!! warning "闭包捕获的是变量，不是值"
    循环里用 `var` 声明计数器，所有回调共享同一个变量，定时器触发时它已经等于循环结束值。改用 `let`，每次迭代创建新的绑定。

不允许的写法：把整篇正文放进提示块；一页出现三个以上提示块；提示块里只有一句"注意"而没有内容。

## 代码块

1. **必须带语言标记**，才能高亮与复制。
2. **超过 15 行必须分段**，每段之后用一段文字解释这一段做了什么，再继续下一段。
3. **每个关键行带注释**，注释写"为什么"，不复述"是什么"。
4. 需要强调的行用 `hl_lines` 标出。
5. 未经运行验证的代码，在代码块前标注"示意代码：未通过自动验证"。

```js title="防抖：连续触发只执行最后一次" hl_lines="3 4"
function debounce(fn, wait) {
  let timer = null;               // 闭包保存定时器句柄
  return function (...args) {
    clearTimeout(timer);          // 新的触发先取消上一次
    timer = setTimeout(() => fn.apply(this, args), wait);
  };
}
```

## 表格

表格用于**多个对象在多个维度上的对比**。只有一个维度时用列表。印刷时采用三线表：只保留表头上下线与表尾线，表头在跨页时重复。

| 方案 | 适用场景 | 代价 |
|---|---|---|
| 切片字体 | 网页，按需加载 | 请求数多 |
| 合并字体 | PDF，本地读取 | 单文件大 |

## 图

图的规则单独成页，见 [图标与图表工具箱](icons-and-diagrams.md)。这里只规定版式：

- 图上方有一句话说明"这张图要看什么"。
- 图下方有编号列表，逐步解释图中的流转。
- 图的文字大小不得小于正文的 80%。

## 间距节奏

同级元素之间使用统一间距，章节层级越高，上方留白越大。标题与其后第一个元素之间不得被分页隔开，书籍中通过"标题加后续内容整体不拆分"实现。
