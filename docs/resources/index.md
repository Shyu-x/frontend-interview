# 教学资源参考

本栏目收录经过链接核验的权威资料：官方文档、标准规范、MDN、web.dev、经典书籍、课程与长期维护的学习站点。每条资料标注类型、语言、适合人群与难度，并说明怎么学。

## 怎么使用本栏目

!!! tip "这一组怎么学"
    不要从头到尾浏览。先确定你现在要解决的问题，进入对应页面，只选 1 到 2 个资源完成，再回来。

1. 如果你不知道从哪里开始，先读 [前端学习路线](learning-paths.md)，按阶段与周计划推进，通过自测清单再进入下一阶段。
2. 如果你知道要学的主题，用下面的“学习目标对应页面”表直接进入分类页。
3. 每个分类页的每一组都以“这一组怎么学”开头，先读它再看表格。
4. 表格中的“适合谁与难度”用于筛选，“怎么学”给出具体动作。动作做完才算学完。
5. 学完一个主题后，用 [面试练习](interview-practice.md) 检查是否能主动回忆。

!!! tip "这一组怎么学"

| [React 官方中文文档](https://zh-hans.react.dev/) | 文档 | 中文 | 初到中级，入门到进阶 | 官方教程与参考，先完成教程再读“Escape Hatches” |
